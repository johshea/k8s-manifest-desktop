# Architecture

## Project layout

This repository is standalone. The generator core (`manifest_gen.py`, `cluster_config_gen.py`,
`clusterplatforms/`, `addons_gen.py`, `addons/`, `app_templates.py`, `field_docs.py`, `providers.py`
and their tests) lives here and has no GUI dependency; nothing has to be kept in sync with another project.

It started as one half of an earlier combined desktop + web project, which is now **legacy** (it predates the split and does not have the Networking & Storage mode).

## Using the generator from code

```python
import manifest_gen as gen
res = gen.generate("Deployment", {"name": "web", "image": "nginx:1.27", "replicas": "3"})
if res.ok:
    print(gen.to_yaml(res.manifest))      # also: gen.to_multi_yaml([...]), gen.filename_for(m)
else:
    print(res.errors)
```

Unspecified fields fall back to the same defaults the GUI shows. Table fields take a
list of dicts (or a JSON string) using the column keys from `gen.TABLE_FIELDS`:

```python
gen.generate("Deployment", {
    "name": "web", "image": "nginx:1.27", "volumes": "logs:emptyDir::",
    "extra_containers": [
        {"role": "sidecar (native)", "name": "proxy", "image": "envoyproxy/envoy:v1.31.0"},
        {"role": "sidecar (regular container)", "name": "log-shipper",
         "image": "fluent/fluent-bit:3.1", "volume_mounts": "logs:/var/log/app:ro"},
    ],
    "tolerations": [{"key": "dedicated", "operator": "Equal", "value": "web", "effect": "NoSchedule"}],
    "node_affinity": [{"type": "required", "key": "kubernetes.io/os", "operator": "In", "values": "linux"}],
    "pod_anti_affinity": [{"type": "preferred", "key": "app", "operator": "In", "values": "web",
                           "topology_key": "kubernetes.io/hostname", "weight": "100"}],
})
```

Validation for these covers unique container names across `containers` and
`initContainers` (the main container is named after the resource unless you set
*Container name*), volumeMounts that reference undefined volumes, toleration rules
(`Exists` ⇒ no value, empty key ⇒ `Exists`, `tolerationSeconds` ⇒ `NoExecute`), operator
vs values (In/NotIn need values, Exists/DoesNotExist none, Gt/Lt one integer), weights
1-100, and required topologyKeys. Required node-affinity rows with the same *term #* are
ANDed; different term numbers are ORed (separate `nodeSelectorTerms`).
